#Tips to run the project

For a Customer user: 

1-For any customer to use any service of the systme he should have an account (must sign up).
2-The user must write his email and password as path varibles in the url when using a service(http://localhost:8080/FinancialController/paywallet/a/1) "a" s email and 
"1" is password
3-If the customer wants to make a refund request he should have a complete transaction (such as payment transaction) to make arefund on it such as payment transaction
4-If the customer wants to check for a refund request he has done and the admin did not handle it he must be informed that his request is in waiting list rather than that his request is accepted or rjected.
5-To sign in , the customer should enter his passowrd and email correctly.
6-When signing up the customer should enter his wallet balance.


For an admin user:

1-To do a service the admin must write his user name and password as path variables in the url (name "admin" password "12345").If the admin wrote a wrong name or password there will be a resonse that any of admin data entered is wrong.

*Project will run on java version 11 or any hiegher version.
